# DevOps Practice Repo

DevOps assignments and project: Docker, Kubernetes, CI/CD, and monitoring.

## Folders

| Folder | Contents |
|--------|----------|
| **02-docker-containerization-labs** | Docker basics, Python+Redis and PHP+MySQL with Docker Compose |
| **03-kubernetes-workloads-and-services** | K8s deployments, services, PV/PVC, ConfigMaps, Secrets, Ingress |
| **04-kubernetes-observability-and-apps** | Prometheus/Grafana setup, Guestbook app with Redis leader-follower |
| **Project** | Nginx–Node.js–Redis stack: `01-dockerize-app`, `02-k8s-build-and-deploy`, `03-cicd-github-actions`, `nginx-nodejs-redis` |
| **.github/workflows** | CI/CD: build and push images on release, deploy to Kubernetes |

Each folder has task subfolders (e.g. `01-docker-basics`, `02-python-redis-compose`) with READMEs and configs.
